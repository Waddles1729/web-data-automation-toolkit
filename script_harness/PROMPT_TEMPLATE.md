# 変換ロジック生成プロンプト（生成AI用）

案件が来たら、サンプルデータと仕様を以下のテンプレに埋めて生成AI（ChatGPT / Claude 等）に渡せば、
`transforms/<name>.py` に貼るだけの `transform()` 関数が得られる。あとは検証して納品。

---

```
Python のデータ変換関数を書いてください。
以下の仕様で transform(rows: list[dict]) -> list[dict] を 1 つ。
- rows の各要素は入力1行の dict（キー＝列名）
- 標準ライブラリのみ（pandas等の外部依存は使わない）
- 返り値も list[dict]
- 関数本体だけ。説明は不要

## 入力サンプル（先頭数行）
{ここに元データを3～5行貼る}

## 期待する出力サンプル
{完成形を2～3行貼る}

## 変換ルール
{箇条書きで}

## エッジケースの扱い
{例: 空欄はスキップ / 不正な日付はそのまま残す など}
```

---

## 使う流れ
1. 上のプロンプトで関数を生成
2. `transforms/案件名.py` に保存
3. `python convert.py --in サンプル.csv --out 確認.xlsx --transform 案件名 --preview` で先頭5件確認
4. 問題なければ `--preview` を外して全件処理 → 検証 → 納品
